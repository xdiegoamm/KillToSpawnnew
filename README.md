# Kill To Spawn — Fabric 1.20.1

Mod cliente para Fabric 1.20.1.

- Detecta mensajes de kill donde el asesino es el jugador local.
- Funciona para cualquier jugador asesinado; no está fijado a un nombre concreto.
- Ejecuta `/spawn` después de detectar la kill.
- Tecla K para activar/desactivar.
- Comandos: `/killspawn on`, `/killspawn off`, `/killspawn toggle`.

## Compilar con GitHub Actions
1. Sube el contenido de esta carpeta al repositorio.
2. En GitHub abre **Actions**.
3. Selecciona **Build KillToSpawn**.
4. Pulsa **Run workflow**.
5. Al terminar, abre la ejecución y descarga el artefacto `KillToSpawn-Fabric-1.20.1`.
